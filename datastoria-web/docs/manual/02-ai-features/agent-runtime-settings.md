# 智能体运行参数与治理

DataStoria 的 AI 智能体（AgentScope Harness 运行时）有一组服务端持有的运行参数，控制单轮对话的
推理-工具循环上限、上下文压缩时机、超大工具结果的处理方式，以及服务停止时在途会话的结算窗口。
这些参数**不暴露给普通用户、也不接受请求级设置**，按下面的层级解析：

```text
租户级管理员配置（设置 → AI → 智能体 → 运行参数，存数据库）
        ↓ 未覆盖的项
进程默认值（conf/datastoria.env 中的 DATASTORIA_AGENT_* 环境变量）
```

无论来自哪一层，数值都会被服务端钳制到绝对范围内，数据库里被手工改坏的值在读取时同样会被收敛。

## 可配置的运行参数

| 参数 | 环境变量（进程默认） | 绝对范围 | 作用 |
|---|---|---|---|
| 最大迭代轮数 | `DATASTORIA_AGENT_MAX_ITERS`（默认 25） | 1–100 | 单条消息内"推理 → 工具调用"循环的轮数上限。多工具技能工作流（生成 SQL → 校验 → 执行 → 出图）通常需要 10 轮以上；轮数耗尽时模型会提前收尾 |
| 工具结果卸载阈值（字符） | `DATASTORIA_AGENT_TOOL_RESULT_EVICTION_CHARS`（默认 32768） | ≥ 2048 | 单条工具结果超过该大小时全文落盘，模型上下文只保留首尾预览；`execute_sql` 的结果在工具层另有行数/单元格/总量的独立裁剪 |
| 压缩触发比例 | `DATASTORIA_AGENT_COMPACTION_TRIGGER_RATIO`（默认 0.8） | 0.1–0.95 | 上下文压缩在"模型上下文窗口 × 该比例"时触发。模型窗口来自模型配置中的 `contextWindowTokens`（设置 → AI → 模型） |
| 回退上下文窗口（tokens） | `DATASTORIA_AGENT_COMPACTION_FALLBACK_CONTEXT_TOKENS`（默认 100000） | ≥ 8192 | 模型未上报窗口时使用的回退值；默认组合（0.8 × 100K = 80K）与框架历史行为一致 |

两个进程级参数不进入租户覆盖，只能通过环境变量设置：

| 参数 | 环境变量 | 作用 |
|---|---|---|
| 运行数据目录 | `DATASTORIA_AGENT_DATA_DIR`（默认 `~/.datastoria.agent`） | AgentScope 运行数据（卸载的工具结果全文等）的落盘根目录；启动时创建，不可用则快速失败 |
| 优雅停机等待 | `DATASTORIA_AGENT_SHUTDOWN_TIMEOUT_SECONDS`（默认 20） | `bin/datastoria stop` 发出 SIGTERM 后，在途智能体运行最长结算时间；停止脚本会等待更久（30 秒）后才强制终止 |

## 管理员配置入口

设置 → AI → 智能体页面底部的**智能体运行参数（管理员）**区块：

- 仅管理员（ADMIN 角色）可见、可保存；普通用户不显示该区块。
- 每个输入框留空即表示"跟随配置文件默认值"（以占位符显示当前默认）。
- 保存后写入租户级配置（`settings.ai.agent.harness`），对当前租户的所有智能体会话立即生效——
  下一条消息发起的运行即按新值执行，无需重启服务。
- 接口为 `GET/PUT /api/admin/ai/harness-settings`，带 `If-Match` 乐观锁，非管理员调用返回 403。

同页面其余选项（上下文裁剪、输出推理摘要、响应语言、错误自动解释等）是每个管理员账号自己的
偏好设置，不影响其他用户。

## 权限边界

**设置 → SQL → 查询上下文**与**设置 → AI → 智能体**两个页面均为管理员专属：

- 普通用户的设置对话框不显示这两个入口，回退到"界面"页。
- 查询上下文中的 ClickHouse 会话设置会随每条查询下发并被服务端护栏钳制（只能调紧），
  属于平台级配置，因此同样只允许管理员维护。
- 模型与技能页面不受影响：模型页仍由管理员管理，技能页对所有用户只读浏览。

## 运行行为说明

- **上下文压缩**：对话超过触发阈值时，历史前缀被摘要为结构化总结并保留最近若干条原文；
  模型真正报上下文溢出时框架会强制压缩并重试一次。压缩与摘要使用主模型的脱敏包装，
  不会在日志中回显提示词或凭据。
- **工具结果防护**：`execute_sql` 结果进入对话前会被裁剪（行数 ≤ 200、单值 ≤ 2000 字符、
  总量预算约 192K 字符），并附带 `truncated` 标记与改写建议；其他工具结果超过卸载阈值时
  落盘到运行数据目录、只留预览。两层防护保证宽结果**降级可用**而不是整条报错。
- **优雅停机**：SIGTERM 后运行时停止接受新的推理/动作，中断在途运行并结算状态；
  `bin/datastoria stop` 先发 SIGTERM、等待至多 30 秒后才 SIGKILL。
